أساسيات الحاسوب

٤. مراجعة أساسيات الحاسوب

مراجعة

فهم أساسيات الحاسوب والإنترنت وأدوات المطورين

  • اللوحة الأم Motherboard : تضم كافة "وحدات الذاكرة" (the memory) و"الموصلات" (connectors) و"محركات الأقراص الصلبة" (hard drives) اللازمة لتشغيل الحاسوب، وتُعد بمثابة "لوحة الدوائر الرئيسية" (the main circuit board) فيه.

  • وحدة المعالجة المركزية - (CPU) - Central Processing Unit : معالج مسؤول عن تنفيذ التعليمات وإجراء العمليات الحسابية.

  • ذاكرة الوصول العشوائي - (RAM) - Random Access Memory : موقع تخزين مؤقت لـ"وحدة المعالجة المركزية" (CPU) في الحاسوب.

  • محرك الأقراص الصلبة - (HDD) - Hard Disk Drive : وحدة تخزين دائمة تُستخدم لحفظ البيانات حتى عند إيقاف تشغيل الحاسوب.

  • محرك الأقراص ذو الحالة الصلبة - (SSD) - Solid State Drive : ذاكرة فلاش "غير متطايرة" 1 يمكن استخدامها بدلاً من "القرص الصلب" (hard drive) .

  • وحدة تزويد الطاقة - (PSU) - Power Supply Unit : مسؤولة عن تحويل الكهرباء القادمة من مقبس الحائط إلى شكل يمكن للكمبيوتر استخدامه.

  • وحدة معالجة الرسومات - (GPU) - Graphics Processing Unit : مسؤولة عن عرض الصور والرسوميات على شاشة الكمبيوتر.

  • أنواع مختلفة من "مزودي خدمة الإنترنت" (Internet Service Providers) : مزود خدمة الإنترنت (ISP) هو شركة توفر إمكانية الوصول إلى شبكة الإنترنت. وهناك أنواع مختلفة من مزودي الخدمة، تشمل الاتصال الهاتفي (Dial-up) ، و DSL ، والكابل ، و"الألياف الضوئية" (fiber-optic) ، و"الأقمار الصناعية" (satellite) .

  • "طرق آمنة" Safe Ways لتسجيل الدخول إلى جهاز الكمبيوتر الخاص بك : تشمل أمثلة الطرق الآمنة لتسجيل الدخول استخدام كلمة مرور قوية، وتفعيل "المصادقة الثنائية" (two-factor authentication) ، واستخدام برنامج لإدارة كلمات المرور.

  • بيئة التطوير المتكاملة - (IDE) - Integrated Development Environment : أداة تساعد المطورين على كتابة الكود واختباره وتصحيح أخطائه بكفاءة.

  • محرر الأكواد Code Editor : أداة يستخدمها المطورون لكتابة الأكواد البرمجية وتصحيح أخطائها.

  • Git : نظام شائع لـ"التحكم في الإصدارات" (version control) يتيح للمطورين تتبع التغييرات في "الكود المصدري" (code) والتعاون مع الآخرين.

  • خدمات استضافة المستودعات القائمة على السحابة Cloud-based Hosting Services for repositories : "المستودع" (repository) هو موقع لتخزين ملفات المشروع و"سجل الإصدارات" (version history) . وتشمل "خدمات الاستضافة السحابية" (cloud-based hosting services) الشهيرة للمستودعات كلًا من GitHub و GitLab و Bitbucket .

  • مدير الحزم Package Manager : أدوات تساعد المطورين على تبسيط عملية إضافة وتحديث وإزالة "المكتبات" (libraries) و"اعتمادات المشروع" (project dependencies) . ومن الأمثلة عليها: npm و pip و Maven .

  • مكتبات وأطر عمل الاختبار Testing Libraries and Frameworks : تُجرى "عمليات الاختبار" (Testing) في البرمجيات لضمان عمل الكود البرمجي كما هو متوقع. ومن الأمثلة على مكتبات وأطر عمل الاختبار: Jest و PHPUnit و JUnit .

التعامل مع الملفات وأنظمة الملفات وتنسيقات الوسائط

  • أفضل الممارسات لتسمية الملفات : يُستحسن تسمية الملفات بطريقة يسهل فهمها وصيانتها; فعلى سبيل المثال، يُعد الاسم about-us.html أكثر دلالةً ووضوحاً من الاسم page1.html .

  • الدليل الجذري root directory : "الدليل الموجود في أعلى مستوى" (top-level directory) ضمن "نظام الملفات" (file system) . "الدليل" (Directory) هو مسمى آخر لـ"المجلد" (Folder) .

  • Markdown : لغة ترميز تُستخدم عادةً لإعداد الوثائق وملفات README . وملف README هو ملف يحتوي على معلومات حول مشروع ما، مثل كيفية تثبيته واستخدامه.

  • index.html : يمثل "الصفحة الافتراضية" (the default page) التي تظهر عند زيارة المستخدم لموقع إلكتروني.

  • إنشاء الملفات والمجلدات ونقلها وحذفها باستخدام Explorer أو Finder : يُعد Explorer مدير الملفات في نظام Windows ، بينما يُعد Finder مدير الملفات في نظام macOS . ويمكنك استخدام هذه الأدوات لإنشاء الملفات والمجلدات ونقلها وحذفها.

  • "البحث" (Searching) عن الملفات والمجلدات : يمكنك استخدام ميزة البحث في Explorer أو Finder للعثور على الملفات والمجلدات الموجودة على جهاز الكمبيوتر الخاص بك.

  • أنواع ملفات HTML و CSS و JS : يُستخدم الامتداد .html لملفات HTML ، والامتداد .css لملفات CSS ، والامتداد .js لملفات JavaScript .

  • تنسيقات الصور والرسوميات الشائعة : يُعد كل من JPEG و PNG من تنسيقات ملفات الصور الشائعة. وهناك تنسيق شائع آخر للصور هو GIF ، والذي يدعم الرسوم المتحركة. أما SVG فهو تنسيق مخصص للرسوميات المتجهة (Vector Graphics) .

  • صيغ الصوت والفيديو الشائعة : تُستخدم صيغة MP3 بشكل شائع للملفات الصوتية، وتُستخدم صيغة MP4 بشكل شائع لملفات الفيديو، أما صيغة MOV فقد طورتها شركة Apple وتُستخدم بشكل شائع لملفات الفيديو.

  • تنسيقات الخطوط الشائعة : يُستخدم تنسيق TTF عادةً لخطوط TrueType ، بينما يُستخدم تنسيق WOFF لخطوط الويب. ويُعد تنسيق WOFF2 هو الإصدار اللاحق لـ WOFF ، حيث يوفر ضغطاً أفضل.

  • ZIP : تنسيق ملفات يُستخدم لضغط الملفات والمجلدات.

تصفح الويب بفعالية

  • ما هو "متصفح الويب" Web browser ؟ : هو "تطبيق برمجي" (software application) يتيح للمستخدمين الوصول إلى مواقع الويب وعرضها على شبكة الإنترنت.

  • ما هو "محرك البحث" Search Engine ؟ : "أداة" (tool) تتيح للمستخدمين البحث عن معلومات على شبكة الإنترنت. ومن الأمثلة عليه: Google و Bing و Yahoo .

  • متصفحات الويب الشائعة : تشمل بعض الأمثلة على متصفحات الويب الشائعة Google Chrome و Mozilla Firefox و Microsoft Edge .

  • "استراتيجيات البحث" Search Strategies الشائعة : يمكنك استخدام site: متبوعاً بعنوان الموقع (URL) للبحث عن محتوى داخل ذلك الموقع. كما يمكنك استخدام filetype: متبوعاً بامتداد الملف للبحث عن ملفات من هذا النوع. ويمكنك أيضاً وضع علامة الطرح (-) قبل مصطلح البحث لاستبعاد النتائج التي تتضمن ذلك المصطلح، أو وضع علامة الجمع (+) قبله لتضمين النتائج التي تحتوي عليه.
